# Smart Industrial Safety Monitoring System Using LPC2129

## 📌 Project Overview

The **Smart Industrial Safety Monitoring System Using LPC2129** is an embedded systems project designed to improve safety in industrial environments.

The system uses the LPC2129 ARM7 microcontroller to monitor industrial conditions through different sensors. It continuously collects sensor data, detects abnormal conditions, and provides alerts to prevent potential industrial accidents.

The main objective of this project is to provide a reliable and efficient safety monitoring solution using embedded technology.

## 🎯 Objectives

- Monitor industrial environmental conditions in real time.
- Detect unsafe conditions using sensors.
- Identify abnormal environmental changes.
- Generate alerts when dangerous conditions are detected.
- Improve industrial worker safety.
- Reduce the risk of industrial accidents.

## ⚙️ Working Principle

1. The sensors continuously monitor the industrial environment.
2. Sensor readings are collected by the LPC2129 microcontroller.
3. The microcontroller processes the sensor data.
4. The processed values are compared with predefined threshold levels.
5. If any abnormal condition is detected, the system activates an alert.
6. The LCD displays the monitoring status and warning messages.
7. The buzzer and LED indicators notify users about unsafe conditions.
